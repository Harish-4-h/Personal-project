# Piggie & Monkey Gift Website 🐷🐒

A one-page HTML/CSS/JS gift website with:
- A swinging monkey hanging from a tree branch
- A piggie that roams across the screen
- One video section
- Four photo placeholders
- Responsive mobile design
- Small interactive details

## Add her real media

Put these files inside `assets/`:

- `video.mp4`
- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`
- `photo4.jpg`

Then replace each photo placeholder in `index.html` with:

<img src="assets/photo1.jpg" alt="Memory 1">

Do the same for photos 2–4.

The video is already wired to `assets/video.mp4`.

## Run it

You can simply open `index.html` in a browser.

For a smoother local development experience, use VS Code + Live Server.

## Notes

Everything is plain HTML, CSS and JavaScript. No framework or build step is required.
